# 역행렬 계산 프로그램

n × n 정방행렬을 입력받아 **두 가지 방법**으로 역행렬을 구하고, 결과가 같은지 비교하는 프로그램입니다. (이산수학 리포트)

| 방법 | 원리 | 역행렬이 없을 때 |
|---|---|---|
| 행렬식 (수반행렬) | `A^-1 = adj(A) / det(A)` | `det(A) = 0` → 오류 메시지 |
| 가우스-조던 소거법 | `[A | I] -> [I | A^-1]` | 피벗이 없는 열 → 예외 처리 후 오류 메시지 |

## 실행 방법

Python 3 만 있으면 됩니다. 추가로 설치할 패키지는 없습니다.

```
python inverse_matrix.py
```

## 실행 예시

```
행렬의 크기 n을 입력하세요 (n x n): 2
2 x 2 행렬을 한 행씩 입력하세요. (원소는 공백으로 구분)
  1행: 4 7
  2행: 2 6

[입력 행렬 A]
    [ 4  7 ]
    [ 2  6 ]
가우스-조던 소거 과정을 출력할까요? (y/n): n
------------------------------------------------------------
[방법 1] 행렬식 이용 :  A^-1 = adj(A) / det(A)
  det(A) = 10
  A^-1 =
    [  3/5  -7/10 ]
    [ -1/5    2/5 ]
------------------------------------------------------------
[방법 2] 가우스-조던 소거법 :  [A | I] -> [I | A^-1]
  A^-1 =
    [  3/5  -7/10 ]
    [ -1/5    2/5 ]
------------------------------------------------------------
[비교 결과] 두 방법으로 구한 역행렬이 동일합니다. (일치)
[소수 표현] 소수점 넷째 자리까지
    [  0.6000  -0.7000 ]
    [ -0.2000   0.4000 ]
[검산] A x A^-1 = I  -> 성립
```

## 기능

기본 기능

1. 정수 n 과 n × n 행렬을 행 단위로 입력받아 2차원 리스트에 저장
2. 행렬식을 이용한 역행렬 계산 (`inverse_by_determinant`)
3. 가우스-조던 소거법을 이용한 역행렬 계산 (`inverse_by_gauss_jordan`)
4. 두 결과를 각각 출력하고 동일한지 비교

추가 기능

- 분수(`Fraction`) 정확 연산: 오차 없이 계산하고, 정수·소수·분수 입력을 모두 허용
- 입력 검증: 잘못된 입력이 들어오면 종료하지 않고 다시 입력받음
- 가우스-조던 소거 과정 단계별 출력 (y / n 선택)
- 검산: `A x A^-1 = I` 확인
- 두 방법의 실행 시간 비교
- 반복 실행: 종료를 선택할 때까지 여러 행렬을 이어서 계산
